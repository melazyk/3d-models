# phone-tag

Двухцветная табличка 2 мм с номером телефона на каждой стороне и ушком с отверстием Ø10.

- Пластина 100 × 28 мм, R4 углы; общий габарит 100 × 57 × 2 мм.
- Ушко: центр отверстия Ø10 на 20 мм выше верхнего края пластины, обод 4 мм,
  «треугольник» с основанием 44 мм и плавным переходом R8 к пластине.
- Цифры — заподлицо вставка глубиной 0.6 мм (3 слоя) с каждой стороны (сердцевина 0.8 мм).
  Лицевая: `+7 (915) 328-89-01`, обратная: `+7 (916) 236-21-56` (зеркалится,
  читается при повороте таблички вокруг вертикальной оси).

Все размеры и тексты — в `P` в `model.py`.

## Сборка

```
python build.py models/phone-tag
```

Пишет в `build/phone-tag/`:
- **`part.3mf`** — открывать его: один объект из двух частей, филамент 1 = пластина,
  филамент 2 = цифры (уже назначены);
- `color1_plate.stl`, `color2_text.stl` — те же части по отдельности;
- `preview.png` — цветное превью;
- `part.stl` — слитое одноцветное тело (только для проверок, цифр на нём не видно).

## Печать

- Плашмя, без поддержек, PLA/PETG, слой 0.2 мм (вставка = 3 слоя).
- Bambu Studio: открыть `part.3mf`, в слоты AMS 1/2 поставить цвет пластины и цифр.
  Если слайсер предложит — загрузить «только геометрию», назначение частей сохранится.
- Если назначение не подхватилось: правый клик по части `text` → Change filament → 2.
- Цифры утолщены на 0.15 мм на сторону (`P.text_bold`), штрих ~1.7 мм = 4 линии
  по 0.42 мм. Если в штрихах всё равно видны щели: Quality → Wall generator →
  **Arachne** (он заполняет тонкие места стенками переменной ширины).
  Белые шарики в превью слайса — маркеры швов (Legend → Seams), не дыры.
- Смена цвета идёт на первых и последних 3 слоях — prime tower обязательна.
